# AI & Machine Learning ITI Bootcamp

## 📖 Overview
This repository contains my coursework, lab assignments, and projects from an intensive 3-week Artificial Intelligence and Machine Learning program. The course covered the theoretical mathematics behind machine learning algorithms and practical, hands-on implementation using Python, Scikit-Learn, and Deep Learning frameworks.

## 🚀 Course Structure & Topics Covered

### Week 1: The Foundations
* **Python Programming:** Data structures, control flow, and functions.
* **Mathematical Bedrock:** Linear Algebra and descriptive/inferential Statistics.
* **Data Handling:** Utilizing `NumPy` and `Pandas` for data manipulation.

### Week 2: Core Machine Learning & Deep Learning
* **Data Preprocessing:** Handling missing data, feature scaling, and categorical encoding using `Scikit-Learn`.
* **Supervised Learning:** Implementing Simple Linear Regression, Multiple Linear Regression, and Logistic Regression.
* **Neural Networks:** Introduction to Single-Layer Perceptrons (SLP) and Multi-Layer Perceptrons (MLP).
* **Deep Learning (DNNs):** Tackling vanishing/exploding gradients with Batch Normalization, appropriate weight initialization, and early stopping.

### Week 3: Advanced Architectures & Final Project
* **Advanced Neural Networks:** Autoencoders and Recurrent Neural Networks (RNNs).
* **Final Project:** Comprehensive application of learned concepts to real-world datasets.

## 🧰 Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Deep Learning:** TensorFlow / Keras
* **Visualization:** Matplotlib, Seaborn
* **Explainable AI:** SHAP

## 📂 Highlighted Case Studies
Throughout the repository, you will find detailed code implementations for various datasets, including:
* Breast Cancer Diagnosis (Binary Classification)
* Boston Housing Prices (Regression)
* Pima Indians Diabetes Prediction
* Credit Card Fraud Detection (Handling Imbalanced Data)
* Titanic Survival Prediction

## ⚙️ How to Run
Most scripts are self-contained and run on standard datasets (either built into `sklearn` or fetched via `fetch_openml`). For Kaggle-specific datasets, ensure you have the required `.csv` files in the same directory as the scripts or update the `pd.read_csv()` paths accordingly.
